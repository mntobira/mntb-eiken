# マナトビ英検 一次筆記（リーディング＋ライティング）独自教材 制作仕様書

> **対象読者**: 本リポジトリで英検予想問題・演習教材を制作・改訂するすべての AI エージェント（Claude / GPT / Manus / Gemini 等）および教材執筆者  
> **位置づけ**: 塾の授業・宿題・演習でそのまま使用できる高品質なオリジナル一次筆記教材を、**アプリ内演習（分野別練習・通し模試・ライティング練習）と印刷用PDF冊子（問題・解答用紙・解答解説）で完全同一原本から生成**するための公式技術仕様書です。全8級（5級〜1級）の公式過去問実測ベンチマークに基づく定量キャリブレーション規定を含みます。

---

## 0. 絶対原則と禁止事項（AI作問時の最重要ガードレール）

1. **著作権・独自性の厳守（過去問流用の絶対禁止）**
   - 日本英語検定協会の公式過去問・公式サンプル・市販問題集の英文・設問・選択肢・固有名詞置換（数値や人名だけ変えた翻案）・公式ロゴ・表紙デザインは一切使用しないこと。
   - すべての問題に `origin: 'manatobi-original'` を付与し、完全オリジナルの場面・文章・設問を書き下ろすこと。
2. **単一原本からのアプリ・PDF完全同期**
   - Webアプリ側の大問別チャプター（`bookletSectionChapters`）・通し模試（`EikenMockExam`）・ライティング課題（`bookletWritingTasks`）と、印刷用PDF冊子（問題冊子・マーク＆英作文解答用紙・解答解説）は同一原本（`WRITTEN_BOOKLETS`）から一括生成する。
3. **AI作問で頻発する「NG形式・手抜きパターン」の禁止（`validateWrittenExam` で機械拒否）**
   - ❌ **英語メタ指示の混入禁止**: 短文や会話の `prompt` に `Choose the best answer to complete the sentence:` や `Read the passage and choose...` を入れてはならない。空所は必ず半角スペース5つの `(     )` で表記する（語句整序は4枠 `( ____ / ____ / ____ / ____ )` または5枠 `( ____ / ____ / ____ / ____ / ____ )`）。
   - ❌ **筆記大問2（会話）の形式混同禁止**: 筆記の会話問題は「会話中の `(     )` に入る発話を選ぶ空所補充」であり、リスニングPart2のような `Question: What will ...?` 形式にしてはならない。また話者表記は `M1:` / `F1:` ではなく **`A:` / `B:`** を用いる。
   - ❌ **大問1の問題文（stem）への難語詰め込み禁止**: 公式試験では準1級・1級であっても大問1の文脈語自体は明快な標準語彙（B2+比率 8〜10%以下）で書かれ、**空所に入る選択肢だけがターゲット難語**になっている。問題文自体にC1/C2語彙を詰め込んではならない。
   - ❌ **1文あたりの過剰な長文化禁止**: AIは複文を重ねて1文30〜38語の過密文を作りがちである。必ず `GRADE_AUTHORING_SPECS[grade].calibration.readingWordsPerSentence` の範囲（例：4級 8.5–11.5語、3級 10–12.8語、準2級 12.5–16語、2級 16.5–19.5語、準1級 19.5–22.5語、1級 22.5–26.2語）に制御する。
   - ❌ **テンプレ誤答解説の禁止**: `distractorReasons` に「この文の時制・形・意味に合いません」「本文の情報と一致しない内容です」「本文にありません」といった汎用コピペ文を書いてはならない。**なぜその選択肢が不適切なのか（品詞・語法・時制・本文のどの記述とどう食い違うか）を1肢ずつ個別具体的に日本語で解説**すること。
   - ❌ **ラベル替え水増し禁止**: 同じ問題を別ラウンドに流用してはならない（`validateReleasedBooklets` が全8級・全120冊横断で重複シグネチャを検出してビルドを停止する）。
   - ❌ **正答番号の偏り・連続禁止**: 1冊あたり各番号（`0, 1, 2, 3`）が `N/4 ± 2` 個以内に均等分散し、同一番号の連続は最大2〜3回以内（4連続以上は機械拒否）に抑えること。
   - ❌ **英文中のAI特有のem-dash（`—`）多用・無関係ダミー選択肢の禁止**: パッセージや会話文で `—` を使った挿入構文を多用せず、自然な英語句読法を用いる。読解の誤答選択肢には**本文の重要語彙を35〜55%再利用**しつつ、因果の逆転・主語や範囲のすり替え・留保条件の断定化によって誤りとなる精緻なディストラクターを作ること。

## 2. セクション別の執筆・定量校正・組版ルール

### 2.1 短文の語句空所補充 (`short`)
- 紙面では **4択横1列（4カラム）または2カラム** に組版されるため、各選択肢は原則 **1〜3語（最大でも約22文字以内）**、4肢すべての品詞・活用形（語尾 `-ed` / `-ing` / `-tion` 等）を揃える。
- **語彙難度（選択肢平均Zipf / C1+比率）と句動詞枠**:
  - **5級**: Zipf 5.1–5.8（うち4〜5問は代名詞・疑問詞・動詞活用の形態識別）
  - **4級**: Zipf 4.9–5.5、熟語2〜4問
  - **3級**: Zipf 4.7–5.3、熟語3〜5問
  - **準2級**: Zipf 4.4–5.0、句動詞・連語4〜6問
  - **準2級プラス**: Zipf 4.2–4.7（C1+ ≤ 5%）、句動詞4〜7問
  - **2級**: Zipf 4.1–4.6（C1+ ≤ 8%）、句動詞・連語5〜7問
  - **準1級**: Zipf 3.55–3.90（C1+ 15–24%）、後半問15〜18に句動詞4問
  - **1級**: Zipf 3.05–3.35（B2+ 75–86%、C1+ 38–52%）、問1〜18はC1/B2上位単熟語、**問19〜22は句動詞4問**。stem語数は **16〜28語（平均22語前後）** で文脈語のB2+比率は **8.5%以下** に保つ。

### 2.2 会話文の空所補充 (`conversation`：5級〜準2級)
- 紙面では **2カラム×2段** に組版される。`A: ...\nB: (     )` または複数往復対話とする。

### 2.3 日本文付き語句整序 (`reorder`：5級・4級)
- `reorder(japanese, prefix, tokens, order, pairs, answer, explanation)` ヘルパーを使用する。
- 4語群（**1番目・3番目** のペア選択）および公式4級形式の **5語群（2番目・4番目 のペア選択）** の双方に検証器・UI・PDF組版が対応している。

### 2.4 長文の語句空所補充 (`cloze`：準2級〜1級)
- 本文中の空所は必ず通し設問番号と一致する半角丸括弧＋2桁番号で記述する：
  - 準2級：`(21)`〜`(22)`（1パッセージ 210–260語 × 2問）
  - 準2級プラス・2級：パッセージA `(18)`〜`(20)`、パッセージB `(21)`〜`(23)`（各 215–285語 × 3問）
  - 準1級：パッセージA `(19)`〜`(21)`、パッセージB `(22)`〜`(24)`（各 240–285語 × 3問）
  - **1級**：パッセージA `(23)`〜`(25)`、パッセージB `(26)`〜`(28)`（各 **330–365語・3段落** × 3問、平均1文長 20–24語、選択肢平均 4.5–7語）

### 2.5 長文の内容一致選択 (`reading`：4級〜1級)
- パッセージ語数・1文長・選択肢語数・推論比率の目標（`GRADE_AUTHORING_SPECS` 準拠）：
  - **4級**: Notice 80–120語（2問）、Email 145–195語（3問）、Article 195–250語（5問）｜WPS 8.5–11.5
  - **3級**: Notice 95–145語（2問）、Email 180–230語（3問）、Article 240–290語（5問）｜WPS 10–12.8
  - **準2級**: Email 200–260語（3問）、Article 300–360語（4問）｜WPS 12.5–16
  - **準2級プラス**: Email 220–275語（3問）、Article 320–380語（5問）｜WPS 14–17.5
  - **2級**: Email 245–305語（3問）、Article 350–420語（5問）｜WPS 16.5–19.5
  - **準1級**: Article A 380–440語（3問）、Article B 450–520語（4問）｜WPS 19.5–22.5｜選択肢 15.5–21語｜複数文統合・推論 ≥45%
  - **1級**: **Article A 490–555語・4段落（問29〜31の3問）**、**Article B 740–825語・6〜8段落（問32〜35の4問）**｜WPS 22.5–26.2｜B2+ 18–23%、C1+ 4.5–6.8%｜**選択肢 18.5–24.5語**｜**複数文統合・筆者意図/推論 ≥50%**

### 2.6 ライティング (`email` / `summary` / `essay`：3級〜1級)
- 級別の語数・原文語数ルール：
  - **3級**: `email` `[15, 25]`（原文 40–65語、末尾に2つの下線質問） / `essay` `[25, 35]`（`QUESTION`）
  - **準2級**: `email` `[40, 50]`（原文 75–105語、本文中に下線部1か所） / `essay` `[50, 60]`（`QUESTION`）
  - **準2級プラス**: `summary` `[25, 35]`（原文 90–115語） / `essay` `[50, 60]`（`QUESTION`）
  - **2級**: `summary` `[45, 55]`（原文 145–175語） / `essay` `[80, 100]`（`TOPIC` + 3 `POINTS`）
  - **準1級**: `summary` `[60, 70]`（原文 190–225語） / `essay` `[120, 150]`（`TOPIC` + 4 `POINTS` から2つ選択）
  - **1級**: `summary` **`[90, 110]`**（原文 **295–320語**、3段落） / `essay` **`[200, 240]`**（簡潔な **`TOPIC` のみ・`POINTS` なし**、**理由3つ**［序論＋本論3段落＋結論の5段落構成］）

## 3. ビルド＆PDF生成・全自動品質検査の実行

```bash
cd /home/user/webapp/eiken-app
npm run generate:materials   # 単語帳・チャプター索引の再生成（全8級 480語）
npm run generate:booklets    # JSON検証 → 全120冊PDF組版・ロゴ検査・文字重なり検査・WebPプレビュー生成 → ガチャ景品TS生成
npm test                     # Vitest による原本・PDF・リスニング継承整合性テスト
```

## 4. リスニングとの1対1回次結合（全8級・各15回＝120セット）

- **共通の級ID (`EikenGrade`)**: `eiken_5`, `eiken_4`, `eiken_3`, `eiken_pre2`, `eiken_pre2plus`, `eiken_2`, `eiken_pre1`, `eiken_1`
- **共通の回次 (`round`)**: `1` 〜 `15` の整数
- **IDの対応規則**（`src/eiken/writtenAuthoringSpec.ts` の `buildPrimaryBundleRef`）：
  - 一次筆記: `${grade}_written_${round02}`（例：`eiken_1_written_01`）
  - リスニング: `${grade}_listening_r${round02}`（例：`eiken_1_listening_r01`）
