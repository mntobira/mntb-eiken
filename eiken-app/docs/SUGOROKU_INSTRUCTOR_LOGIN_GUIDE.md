## 2. 講師ログイン手順（2つの入口）

用途に応じて、以下の **パターンA（管理者ポータル直行）** または **パターンB（アプリ内設定画面経由）** のどちらからでもログインできます。

### パターンA：管理者ポータル直行URL（`?portal=admin`）から入る【推奨】
日々の学習時間チェック・声掛けアラート確認・教材PDF印刷・英作文／スピーキング添削を行う際のメイン入口です。

1. ブラウザ（Chrome / Safari / Edge）で、アプリの URL 末尾に **`?portal=admin`** を付けて開きます。  
   - 例：`https://<配信ドメイン>/?portal=admin`
2. 「講師・管理者専用 すごろく塾 管理者ポータル」のガード画面が表示されたら、**「講師用 Google アカウントでログイン」** を押します。
3. アカウント選択画面で **`mntobira@gmail.com`** または **`hirokingz0927@gmail.com`** を選択します。
4. ログイン完了と同時に自動でオーナー権限が確認され、管理者ポータルが開きます。
5. 画面右上の切替ピルで **「デモ」⇄「本番」** を切り替えられます。
   - **デモ**：サンプル生徒データで画面操作や面談表示をリハーサルしたいとき
   - **本番**：実際のクラス・在籍生徒のリアルタイム学習ログを確認するとき

### パターンB：通常画面の「設定 ＞ クラス」タブから入る
新しいクラスを作りたいときや、週次の宿題（12週標準ルート等）を配信したいときに使います。

1. 通常の『マナトビ英検』トップ画面を開き、下部ナビゲーション右端の **「設定」** を開きます。
2. 「アカウント連携」欄の **「Google アカウントで連携」** を押し、`mntobira@gmail.com` または `hirokingz0927@gmail.com` でログインします。  
   （すでに別アカウントで入っている場合は **「切り替え」** ボタンから変更できます）
3. ログインすると、上部の **「クラス」** タブ（通常ユーザーには「準備中」と表示される先行機能）が自動的に開けるようになります。
4. 「クラス」タブを開き、下部にある以下のボタンを押します。
   - **「先生の方はこちら（クラスの管理）」**：クラス作成・参加コード確認・宿題配信（`JukuTab`）画面へ移動
   - **「すごろく塾 管理者ポータル（分野別学習時間・PDF棚）」**：パターンAと同じ管理者ポータルへ移動

### iPad / iPhone（Safari）や LINE アプリ内ブラウザでの注意点
- **Safari でポップアップがブロックされてログイン画面が開かない場合**  
  ログインボタンの下に表示される **「iPad / Safari 用：画面遷移（リダイレクト）でログイン」** ボタンを押してください。別ウィンドウを開かず、同じタブのまま Google ログインが完了します。
- **LINE や Instagram のトーク画面内リンクから開いた場合**  
  アプリ内ブラウザでは Google の仕様によりログインがブロックされます。画面右上のメニュー（`…` やコンパスアイコン）から **「ブラウザで開く（Safari / Chrome で開く）」** を選んで開き直してください。

## 3. すごろく塾クラスの作成 ＆ 6文字招待コードの発行

生徒を招待する前に、指導対象のクラスを1つ以上作成します。

1. **「設定 ＞ クラス ＞ 先生の方はこちら（クラスの管理）」** を開き、上部タブの **「クラス管理」**（初回クラス0件時は中央の案内）から **「＋ クラスを作る」** を押します。
2. 以下の項目を入力して **「作る」** を押します。
   - **学校名（塾名）**：例）`オンライン塾 すごろく`（※生徒の画面にも表示されます）
   - **クラス名**：例）`英検2級 2月開講クラス` / `英検準2級 対策クラス`
   - **対象科目（級）**：例）`英検2級`（あとから生徒ごとの個別目標級も設定可能です）
3. 作成が完了すると、読み間違いやすい文字（`0/O`, `1/I/L`, `8/B`, `U/V`）を除外した **6文字の参加コード（例：`ACDEF2`）** が自動発行されます。
4. **塾プラン（`plan: 'juku'`）の有効化確認**：
   - `mntobira@gmail.com` / `hirokingz0927@gmail.com` はオーナー権限を持つため、`createSugorokuJukuClassroom` 経由での作成時は自動で `plan: 'juku'` になります。
   - 標準モーダルから作成した場合は、クラス作成後に `plan: 'juku'` が設定されていることを確認してください（`plan: 'juku'` になると、先生ダッシュボード上に **「宿題・ペース管理（塾向け）」タブ** が表示され、参加した生徒全員の広告が100%非表示になります）。

## 4. 塾生への案内手順（招待コード・広告完全非表示・実名保護）

クラスを作成したら、生徒・保護者へ **「専用リンク」または「6文字の招待コード」** を共有します。

### 生徒へ送る URL（おすすめ：コード自動入力リンク）
以下の形式で URL を LINE 等で送ると、生徒側で6文字コードが最初から自動入力された状態で開きます。

```text
https://<配信ドメイン>/?sugoroku_invite=<6文字の招待コード>
```
（例：招待コードが `ACDEF2` の場合 → `https://<配信ドメイン>/?sugoroku_invite=ACDEF2`）

※ コードを手入力してもらう場合は `https://<配信ドメイン>/?portal=sugoroku` と6文字コードをセットで案内してください。

### 生徒側の初回参加フロー（2ステップ・約1分）
1. **ステップ1（Google 認証）**：学校配布 iPad の Google アカウント、または個人の Gmail アカウントでログインします（iPad Safari でもリダイレクト切替ボタンでそのまま入れます）。
2. **ステップ2（招待コード＆同意チェック）**：
   - 6文字のすごろく招待コードを確認（全角文字や小文字で打っても自動で半角大文字に補正されます）
   - アプリ内ニックネーム（本名でなくてOK）と現在の目標級を選択
   - 「担当講師への学習記録・提出答案の共有」への同意チェックを入れて **「すごろく塾クラスに参加して学習を始める」** を押す

### 参加完了と同時に自動で適用される保護仕様
- **広告 100% 完全非表示（Ad-Free）**：参加完了の瞬間からバナー広告・動画広告が一切表示されなくなります。
- **実名プライバシーの完全分離**：
  - 全国ランキング等の一般公開画面には、生徒が設定したニックネーム（さらに一部マスク処理）のみが表示され、**本名（名簿名）が外部に出ることは絶対にありません**。
  - 講師側は管理者ポータルの生徒詳細画面から **「名簿名（実名・例：佐藤 拓海）」** と **「指導メモ」** を登録でき、これは担当講師・オーナーにしか見えません。

## 5. 日常の指導オペレーション（宿題・時間集計・教材PDF・添削）

### ① 生徒の学習時間・停滞アラート確認（`?portal=admin` ＞「生徒」タブ）
- **声掛け優先ソート**：「初回未学習」「3日以上学習ストップ」「宿題期限超過」の生徒が自動的に一番上にハイライト表示されます。
- **ワンタップ LINE 声掛け文コピー**：生徒行のアクションから、今週の学習時間・残り宿題数を反映した励ましメッセージをコピーしてそのまま LINE 等に貼り付けられます。
- **個人別ドリルダウン**：生徒をタップすると、直近14日間の日別学習時間グラフと、**級×分野別（Reading / Listening / 単語・語彙 / Writing / Speaking）の有効学習時間＆正答率**（1分以上の放置時間は自動除外）を確認できます。
- **面談用 CSV 出力**：「CSV保存」ボタンから、保護者面談や月次報告にそのまま使える Excel 対応（BOM付きUTF-8）一覧表をダウンロードできます。

### ② 日次／週次ペースメーカー宿題の配信（先生ダッシュボード ＞「宿題・ペース管理」タブ）
1. **「＋ 宿題・12週ルートを出す」** を押します。
2. **『英検2級 3か月（12週）標準ルート』プリセット** から該当週を選ぶか、任意の単元と締切日を選択します。
3. **1日あたりの推奨問題数（ペースメーカー）** や配信対象（クラス全員／特定生徒のみ個別配信）を設定して配信します。
4. 生徒がアプリを開いた瞬間、**ホーム画面の最上部に「今日の宿題あと◯問」カードがピン留め表示**され、「今すぐ解く」から1タップで該当単元の演習が始まります。

### ③ 講師用 PDF 教材ダイレクト棚（`?portal=admin` ＞「教材PDF」タブ）
- 生徒向けのガチャ演出やロックを介さず、英検5級〜1級までの全プリント教材・一次筆記3分冊（問題冊子／解答用紙／解説・採点基準）をその場で即プレビュー・印刷・PDF保存できます。

### ④ ライティング添削 ＆ S-CBT スピーキング録音評価（`?portal=admin` ＞「英作文」「スピーキング」タブ）
- **英作文（Writing）**：生徒が提出した英作文（語数・形式チェック結果付き）を確認し、英検4観点スコア・添削文・講評コメントを入力して返却できます。
- **スピーキング（S-CBT方式録音）**：生徒が iPad / スマホ / PC で吹き込んだ音読・No.1〜No.4 の音声をブラウザ上で直接再生し、観点別スコアとアドバイスを返却できます。

## 6. 3人目以降の講師（スタッフ）追加・退塾（一時停止）対応

### 新しい講師アカウントを追加したい場合
`mntobira@gmail.com` / `hirokingz0927@gmail.com` 以外の先生にも管理画面を開かせたい場合は、以下のいずれかで権限を付与できます。

1. **特定クラスだけを担当させる場合（推奨）**
   - 追加する先生の Google アカウントで一度ログインしてもらい、UID を確認します。
   - Firestore の `eiken_sugoroku_members/{先生のUID}` に以下を登録します（オーナーログイン中、または Firebase Console から作成可能）：
     ```json
     {
       "uid": "<先生のUID>",
       "role": "staff",
       "classIds": ["<担当させるclassId>"],
       "active": true,
       "adFree": true
     }
     ```
   - これにより、その先生は指定された `classIds` の生徒データ・提出物だけを閲覧・添削できます（他クラスの生徒情報は見えません）。
2. **環境変数で事前承認メールを追加する場合（Vercel 設定）**
   - Vercel の環境変数 `VITE_SUGOROKU_ADMIN_EMAILS` にカンマ区切りでメールアドレスを設定すると、フロントエンドの事前承認リストに追加されます（既定の `mntobira@gmail.com`, `hirokingz0927@gmail.com` は消えずに維持されます）。※Firestore / Storage ルール側でもオーナー特権を持たせる場合は `eiken_sugoroku_members` への登録を行ってください。

### 生徒の退塾・休塾（アクセス＆広告非表示の停止）
- 退塾・休塾となった生徒については、`eiken_sugoroku_members/{生徒のUID}` の **`active` を `false`** に変更（またはクラスメンバーから除籍）します。
- 変更した瞬間から、以下の制御が即時反映されます：
  1. 塾生ゲート（`?portal=sugoroku`）での再入場ブロック
  2. 広告完全非表示（Ad-Free）の即時解除
  3. ライティング提出・スピーキング録音アップロード・学習ログ送信のサーバー側遮断

## 7. 困ったときのトラブルシューティング（FAQ）

| 症状・表示メッセージ | 原因 | 解決方法 |
|---|---|---|
| 「このアカウントには講師・管理者権限がありません（`insufficient_role`）」と出る | 生徒用または個人の別 Gmail アカウントでログインしている | 「別アカウントへ切替」を押し、`mntobira@gmail.com` / `hirokingz0927@gmail.com` または `staff` 登録済みの Google アカウントを選び直してください。 |
| 設定画面の「クラス」タブに「準備中」と出て開けない | 未ログイン状態、または一般ユーザーアカウントでログインしている | 設定画面の「アカウント連携」から上記講師 Google アカウントでログインすると、即座に「準備中」が外れて開けるようになります。 |
| 管理者ポータルを開いたが生徒がサンプル名（デモ）になっている | 右上のデータ表示切替が「デモ」になっている | 画面右上の **「デモ｜本番」** スイッチの **「本番」** を押してください（担当クラスがある場合は自動で本番データを読み込みます）。 |
| iPad の Safari で「Google アカウントでログイン」を押しても反応しない | 学校 iPad 等のポップアップブロック設定が働いている | ボタン下に表示される **「iPad / Safari 用：画面遷移（リダイレクト）でログイン」** を押してください。 |
| 生徒が招待コードを入れると「似ている文字が含まれています」と出る | 数字の `0`（ゼロ）と `O`（オー）、`1`（イチ）と `I`（アイ）等の除外文字を打っている | 参加コードには紛らわしい文字（`0, O, 1, I, L, 8, B, U, V`）は使われていません。コード文字列をもう一度確認するか、`?sugoroku_invite=XXXXXX` 形式のURLリンクを生徒に送ってください。 |
| 本番環境で初回ログイン後にクラス一覧や保存で権限エラー（`Missing or insufficient permissions`）が出る | コードの PR マージ後に、本番 Firebase へ最新の `firestore.rules` / `storage.rules` がまだデプロイされていない | システム管理者が [`SUGOROKU_SECURITY_DEPLOY.md`](./SUGOROKU_SECURITY_DEPLOY.md) の Step 3 に従い、英検専用 Firebase プロジェクトへルールを1回デプロイしてください。 |
