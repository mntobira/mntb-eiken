# 英検2級・準2級プラス・準2級 語彙CEFR／『パス単』基準 厳密監査レポート

- **対象システム**：『マナトビ英検』（`mntobira/mntb-eiken` / `eiken-app`）
- **監査目的**：オンライン塾「すごろく」様の対象生徒（運動部所属・3か月で英検2級合格を目指す高校生）が、C1/C2等の不要な難語で学習時間を浪費しないよう、収録語彙とリーディング大問1をCEFR基準で全件機械監査し、基礎重視フィルタおよび12週間確認テストを構築する。
- **参照辞書・基準**：CEFR-J Vocabulary Profile 1.5（東京外国語大学 投野研究室公開 A1〜B2辞書）＋ Octanove Vocabulary Profile C1/C2 1.0 ＋ コーパス頻度ランク較正（50,000語）
- **既存資産保全**：既存の一次筆記105回・リスニング120回・`deliverables/listening_retake_minimal/**` は一切変更せず、本ディレクトリのフィルタ＆カリキュラムPDFとして分離出力。

## 1. エグゼクティブ・サマリー（結論）

- 英検2級 リーディング大問1（全15回・255問）の正解語は 82.4% が適正CEFR帯（A2〜B2）内に収まっており、C1以上の過難度正解はわずか 45問（17.6%）のみと極めて高品質。
- 準2級プラス 大問1（255問）の適正率は 89.4%、準2級 大問1（225問）の適正率は 99.6% と本番整合性が高いことを確認。
- 一方、wordbook.tsv（単語帳データ）では、2級（1,000語）のうち低ROIのC1/C2難語が 143語、選択肢解説由来の訳断片・プレースホルダ項目が 735語検出されたため、運動部生向けの『基礎重視モード推奨フィルタ（sugoroku_foundation_vocab_filter.json）』で自動除外リスト化完了。
- 一般単語プール（5,713語）は lv1・lv2・ilv1 がA1〜B2前半中心で2級対策に好適である一方、lv4（1,028語）はC1/C2比率が 30.8% と準1級帯のため、すごろく2級カリキュラムでは lv4 を出題対象外とすることを推奨。
