# マナトビ 英検 オリジナル重点演習

5級・4級・3級・準2級・準2級プラス・2級・準1級の、独立執筆による学習用ユニットです。Hono + TypeScript + Viteで構成しています。

**過去問の転載、言い換え、人物名・数字だけを変えた問題の再利用は禁止です。** 本文・会話・設問・選択肢・解説は今回のユニット用に新しく執筆しました。日本英語検定協会・神戸大学の公式教材ではありません。

## 現在の収録内容

各級に選択式8問（語彙・文法2問、読解4問、聞き取り2問）。3級以上には記述2課題を追加しています。合計で選択式56問、全選択肢の理由224件、記述10課題です。

| 級 | テーマ | 読解本文の語数（各2本） | 記述課題 |
| --- | --- | --- | --- |
| 5級 | 小さな工作室の一日 | 25 / 38 | なし |
| 4級 | 町の小さな活動に参加する | 59 / 65 | なし |
| 3級 | 町の情報を、伝わる形に変える | 81 / 89 | メール・意見 |
| 準2級 | 使いやすい仕組みを考える | 113 / 111 | メール・意見 |
| 準2級プラス | 便利さと参加のしやすさを両立する | 126 / 123 | 要約・意見 |
| 2級 | 数字の向こうにある利用者の行動 | 142 / 144 | 要約・意見 |
| 準1級 | 測定・証拠・説明責任 | 187 / 186 | 要約・意見 |

**本試験1回分の模試ではありません。** 問題数、語数、練習時間、記述の目安語数はこの重点演習独自の設定です。全出題形式を収録した、または公式の最新仕様に完全準拠したと主張するものではありません。

## 品質方針と検証範囲

- 著者レビューでは、正解を支える根拠を本文・会話・文脈中に置き、全誤答に理由を付けています。
- 読解は情報の特定から、目的・条件・留保・代替説明・指標の限界へ、級に応じて文章量と論理構造を変えています。
- 記述には独自の課題、モデル答案、解説、4観点の自己点検を用意。モデル答案は唯一の正解ではありません。
- `npm run test:content` で全56問の選択肢重複、正解インデックス、根拠の所在、解説の欠落、本文・会話の重複、モデル答案の目安語数を検証します。
- `assets/legacy-fingerprints.json` は廃止済みのローカル問題文字列から作った8語連続列のハッシュのみです。元問題の本文は保存していません。新ユニットとの8語一致は検証時0件です。
- `assets/content-quality-report.json` に実際の検証結果、各本文・会話・モデル答案の語数を記録。
- **一致検査は言い換え全般の検出や世界中の教材との網羅的照合ではありません。無断流用が絶対に存在しないことを数学的に証明する検査でもありません。**
- **外部の英語教育専門家による校閲、受験者データによる難度・識別力の測定は未実施。初版として、今後もレビュー・改善が必要です。**

## 機能

- 全7級のページ・級切替・モノクロのマナトビブランド。
- 各級の重点演習、パート別演習、目安タイマー、選択進捗、自動採点。
- 選択式採点後に根拠と4選択肢それぞれの解説を表示。
- 記述は答案欄・参考語数カウント・自己点検・折りたたみ式モデル答案。**自動採点・送信・保存は行いません。**
- ブラウザのWeb Speech APIによる音声、ゆっくり再生、独自放送原稿。
- 解答一覧、空欄解答用紙、A4印刷 / PDF保存、390px幅表示対応。
- 元の神戸大学予想問題で使われた白黒ロゴのみ、ユーザー指定のブランド素材として継続利用。問題内容の流用ではありません。

## データ・構成

- `src/data/original-types.ts`: 制作方針と独立執筆データ型。
- `src/data/original-foundation.ts`: 5級・4級。
- `src/data/original-intermediate.ts`: 3級・準2級。
- `src/data/original-bridge.ts`: 準2級プラス。
- `src/data/original-upper.ts`: 2級。
- `src/data/original-advanced.ts`: 準1級。
- `src/data/sets.ts`: 独立執筆データを演習用に組み立てるだけ。過去問プールや差し替え生成はありません。
- `src/data/grades.ts`: 級メタデータ。
- `OriginalQuestion`: 技能、設問、4選択肢、正解、根拠、4選択肢の理由。
- `OriginalUnit`: 2語彙問、2読解本文、2会話・説明、記述課題、焦点・時間。
- `QuizSet`: 固定ID、級、演習用問題配列、記述、制作方針。
- データはコード内の静的教材。解答や作文はブラウザ表示中のみ存在し、DB、外部評価API、永続ストレージは使用しません。
- APIとHTMLに正解を含むため、不正対策が必要な試験用システムではありません。

## 画像・音声の生成スクリプト

**実際の有料生成は今回も行っていません。** 独立執筆ユニットだけを入力に、7点の装飾用表紙画像と14問分の音声台本を定義しています。表紙画像は問題の正答判定に使いません。

| ファイル | 内容 |
| --- | --- |
| `assets/media-manifest.json` | 新しい7級分のプロンプト・台本・対応ID |
| `scripts/export-media-manifest.mjs` | 稼働中APIから独立執筆ユニットを取得し再作成 |
| `scripts/generate-images.mjs` | Genspark CLIで白黒画像を生成するローカルスクリプト |
| `scripts/generate-audio.mjs` | ElevenLabs REST APIでMP3を生成するローカルスクリプト |
| `scripts/media-common.mjs` | ハッシュ、重複排除、課金確認、安全な出力 |

```sh
# 課金なし・生成なし。デフォルト1件、プロンプトと出力先だけを表示
npm run media:images
npm run media:audio
# 起動中のサーバーから全7級のマニフェストを再作成（これも課金なし）
npm run media:manifest
# 一つのユニットだけに絞る例
npm run media:manifest -- --sets original-pre-1-01
```

実生成には `--execute --confirm-cost` の両方を指定し、費用を確認してから実行します。`--only ID`、`--limit N`、`--manifest PATH`、`--output-dir DIR` が使えます。

- 画像: ローカルの `gsk` CLIと認証、利用可能なプラン・クレジットが必要。モデルは `nano-banana-2-flash-lite`、4:3、1K。
- 音声: `ELEVENLABS_API_KEY` / `ELEVENLABS_VOICE_ID` をローカル環境変数へ設定。`.env` の自動読込はしません。モデルは `eleven_multilingual_v2`、プリセット1話者。キーをコミット・ブラウザ配信しないでください。
- `.media-output/` に保存しgit管理・自動公開の対象外。既存ファイルはスキップ。`--force` は再課金の可能性があります。失敗の自動リトライはしません。
- 現状は1問1ファイル、2回放送や解答待ち時間・複数話者には未対応。
- 有料APIの実生成と品質検査は未実施。生成後に権利・内容・発音を確認し、Web配信処理へ別途接続する必要があります。
- スクリプトはローカル / CI専用で、Cloudflare Workers内では実行しません。

## 起動・テスト

Node.js 22以降。

```sh
npm ci
npm run build
pm2 start ecosystem.config.cjs
# http://localhost:3000
npm run typecheck
npx playwright install chromium # 必要な場合のみ
npm test
npm run test:content
npm run test:media
```

`ecosystem.config.cjs` のcwdは `/home/user/webapp`。別環境では変更します。PM2なしでは `npx wrangler pages dev dist --ip 0.0.0.0 --port 3000` でも起動できます。

- `npm test`: 起動中サーバーに対する全7級の採点・記述・表示・印刷・旧URL20入口の410・404。
- `npm run test:content`: 起動中サーバーの全独立執筆データを検証し品質レポートを更新。
- `npm run test:media`: 課金なし・サーバー不要。マニフェスト、重複排除、dry-run、実行フラグ、安全な出力を検証。
- 接続先は `TEST_BASE_URL` で変更可能。
