### 教材と使い方

- **原本**：`src/eiken/materials/written-booklets.ts`、`reading-round-*.ts`（第1回）、`written-round2-*.ts` / `written-round3-three.ts` / `written-round4-three.ts`（第2〜第4回）。
- **アプリ（分野別練習）**：級 → 語彙・文法練習（短文・会話・整序）／リーディング練習（長文空所・読解）→ `筆記 第N回｜分野名` カード。長文は1本文に複数小問をまとめ、本文を重複表示しません。
- **アプリ（ライティング練習）**：`bookletWritingTasks()` により3級〜準1級の冊子ライティング全24課題を `EikenWriting.tsx` に自動統合。クラウド同期 `s_reading` の `safeId` 規則（`/^[a-z0-9_]{3,80}$/`）を満たす `${grade}_writing_round${letter}${section}` キーで下書き保存・語数カウント・4観点自己点検・参考解答（語数＆和訳付き）を利用できます。
- **ガチャ＆マイPDF**：`print_eiken_<grade>_written_<01..04>` の実在UR 16冊（5級〜準2級10冊は `kyotsu`、準2級プラス〜準1級6冊は `niji`）。語彙ノート7冊と合わせPDF景品23件。マイPDFからセット全体、問題冊子、解答用紙、解答・解説を個別閲覧・保存・印刷できます。
- 公開静的PDFはアクセス制限済みではありません。ガチャ所有UIと厳密な教材アクセス保護は別です。

- **表紙**：マナトビ公式ロゴ、級バッジ、回次、目安時間、大問別配点・自己採点記録表、実施日・氏名欄を配置。
- **問題冊子**：短文は横4列（長選択肢のみ自動2列フォールバック）、会話は `A:`/`B:` 話者強調＋2列、整序は①〜④＋4枠＋1番目・3番目指定。長文空所は太字下線番号 `(21)` 付きで同ページ配置。掲示（Notice）はグレー帯＋外枠、Eメールは差出人ヘッダ帯＋外枠。ライティング課題ページには下線表現・POINTS・点線の構成メモ欄（MEMO / PLANNING NOTES）を配置。
- **解答用紙**：1ページ目はA4横マークシート（自己採点表・塗り方見本付き）。3級〜準1級は2ページ目にA4縦のライティング解答用紙（課題別の語数記入欄・5行ごと目盛り付き英作文罫線・自己点検チェック欄）を収録。
- **解答・解説冊子**：冒頭に復習チェックボックス付き正答一覧表、本文の全文和訳ボックス、全問の【訳】【解き方】と★正答マーク付き全選択肢解説、巻末にライティング参考解答（語数明記・和訳・構成解説・4観点チェックリスト）を収録。
- **機械検査**：全64 PDFに対し、表紙ロゴ画像の存在、未定義グリフ（豆腐 `■`・`IIIIIII`・`\uFFFD`）ゼロ、テキスト行の重なりゼロ、全設問・選択肢・和訳・解説・模範解答の網羅、問題冊子への正答漏洩ゼロ、A4安全余白を `build-written-pdfs.py` で自動検査。
