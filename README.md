# マナトビ 英検5級 演習問題

本試験PDFの出題構成を参考に、リーディング25問・リスニング25問を演習する軽量Webアプリです。Hono + TypeScript + Viteを使用しています。

日本英語検定協会・神戸大学の公式教材ではありません。本試験の完全再現でも、全問が新規のオリジナル問題でもありません。収録問題には提供された過去問をもとに再構成したものが含まれます。

## ページ・API

| パス | 内容 |
| --- | --- |
| `/` | 問題一覧・試験構成 |
| `/exam/:id` | 通し演習50問 |
| `/exam/:id?part=reading` | リーディング25問 |
| `/exam/:id?part=listening` | リスニング25問 |
| `/exam/:id?show=answers` | 解説表示 |
| `/sheet/:id` | 空欄の解答用紙50問、氏名欄・日付欄 |
| `/answers/:id` | 正解一覧 |
| `/script/:id` | リスニング用原稿・和訳 |
| `/new` | 新しい組み替え演習へリダイレクト |
| `/new?part=reading` または `listening` | パート指定の組み替え演習 |
| `/api/sets` | 収録セットの概要JSON |
| `/api/sets/:id` | 問題・解答・原稿のJSON |

`:id` は `2026-2`、`2026-1`、`2025-3`、または `gen-` と36進数シードを組み合わせたID。生成セットはIDから同じ問題内容を再構成します。問題データ内の内部IDはリクエスト間の永続IDではありません。

## 使い方

1. ホームでセットを選び、「問題を開く」を押します。
2. 各問の選択肢を一つクリック。音声は各問の再生ボタンで聞きます。
3. 最後に「採点する」を押すと解答・解説を確認できます。
4. 紙で解く場合は冊子と「解答用紙」を別々に印刷してください。PDF保存は印刷ダイアログで「PDFに保存」を選びます。

## データとストレージ

- `src/data/reading.ts` / `listening.ts`: 収録問題プール。
- `src/data/generate.ts`: 文法テンプレート。
- `src/data/sets.ts`: セット構成、選択肢組み立て、シード付き生成。
- `QuizSet`: セットID、表記、注記、reading/listening配列。
- `QuizItem`: 大問、問題番号、本文、選択肢、正解インデックス、解説、音声テキスト等。
- 内容はコード内の静的教材。ユーザーの解答はブラウザの表示中のみ保持し、DB・外部API・永続ストレージは使用しません。履歴保存はありません。
- `/api/sets/:id` やHTMLには正解も含むため、学習用であり不正防止が必要な試験には使えません。

## ローカル起動・テスト

```sh
npm ci
npm run build
# PM2が利用できる環境
pm2 start ecosystem.config.cjs
# プレビュー: http://localhost:3000
npm run typecheck
npx playwright install chromium # 初回のみ必要な場合
npm test
```

`ecosystem.config.cjs` のcwdはサンドボックスの `/home/user/webapp`。別環境では変更してください。PM2を使わないローカル環境では `npx wrangler pages dev dist --ip 0.0.0.0 --port 3000` でも起動できます。

`npm test` は起動中のサーバーを使います。`TEST_BASE_URL` で接続先を変更できます。固定3セットと生成セットの問数・大問順・問題番号・選択肢数、ブラウザでの全問正解採点、ロゴ表示、印刷時のUI非表示、主要ページの390px表示、空欄解答用紙、不明IDの404を検証します。

## 本試験との差分・未実装

- 本試験の音源、2回の自動放送、例題、厳密な進行制御は未実装。音声は手動再生の合成音声です。
- 通し演習は47分の共通タイマーで、25分経過時のパート自動切り替え・回答ロックはありません。
- 図版は既存の絵文字と日本語説明文等で代替。特にリスニングの図版問題は本試験と同条件にはなりません。
- 選択肢の順序等を再構成しているため、公式解答番号との照合は保証しません。本アプリ内の解答で採点します。
- 組み替え生成は文法テンプレートと収録問題プールの組合せです。毎回50問すべてを新規執筆する機能ではありません。
- 印刷時のページ数・フォントはブラウザ環境に依存。本試験の版面・ページ数の完全一致は保証しません。
- スピーキング、成績履歴、ログイン、他の級は未実装。
- 公開配布前には、収録問題文の権利・転載可否と問題内容を確認してください。元PDF自体はリポジトリに含めません。
