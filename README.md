| パス | 内容 |
| --- | --- |

| `/grades/4` | 4級案内 / 教材準備中 |
| `/grades/3` | 3級案内 / 教材準備中 |
| `/grades/pre-2` | 準2級案内 / 教材準備中 |
| `/grades/pre-2-plus` | 準2級プラス案内 / 教材準備中 |

| `/grades/pre-1` | 準1級案内 / 教材準備中 |
| `/exam/:id` | 5級通し演習50問 |
| `/exam/:id?part=reading` | リーディング25問 |
| `/exam/:id?part=listening` | リスニング25問 |
| `/exam/:id?show=answers` | 解説表示 |
| `/sheet/:id` | 空欄解答用紙50問、氏名欄・日付欄 |
| `/answers/:id` | 正解一覧 |
| `/script/:id` | リスニング原稿・和訳 |
| `/new` | 新しい5級組み替え演習へリダイレクト |
| `/new?part=reading` または `listening` | パート指定の5級組み替え演習 |
| `/api/sets` | 収録セットの概要JSON |
| `/api/sets/:id` | 問題・解答・原稿のJSON |

`:id` は `2026-2`、`2026-1`、`2025-3`、または `gen-` と36進数シードを組み合わせたID。生成セットはIDから同じ問題内容を再構成します。内部の問題IDはリクエスト間の永続IDではありません。未知の級・セットは404です。

## 使い方

1. ヘッダーやホームのカードから級を選びます。演習を利用できるのは現在5級のみです。
2. 5級のセットを開き、各問の選択肢をクリック。音声は各問のボタンで再生します。
3. 最後に「採点する」を押すと解答・解説が表示されます。
4. 紙で解く場合は冊子と「解答用紙」を別々に印刷。PDF保存は印刷ダイアログで選択します。

## データとストレージ

- `src/data/grades.ts`: 級のID、表記、学習目安・テーマ、教材収録状態。
- `src/views/grade.tsx`: 未収録級の案内ページ。5級のホーム・問題画面とは分離。
- `src/data/reading.ts` / `listening.ts`: 5級の収録問題プール。
- `src/data/generate.ts`: 文法テンプレート。
- `src/data/sets.ts`: セット構成、選択肢組み立て、シード付き生成。
- `QuizSet`: セットID、表記、注記、reading/listening配列。
- `QuizItem`: 大問、問題番号、本文、選択肢、正解インデックス、解説、音声テキスト等。
- 教材はコード内の静的データ。ユーザーの解答は表示中のみ保持し、DB・外部API・永続ストレージを使いません。履歴保存はありません。
- APIとHTMLには正解も含むため、不正防止が必要な試験には使えません。

## 画像・音声生成スクリプト

### ファイル

| パス | 役割 |

マニフェストは画像15件・音声46件に重複排除され、元の固定3セットの図版30問分・音声75問分に対応します。`sources` にセットID・大問・問題番号を記録します。第1部は質問と番号付き応答3択、第2部は対話と質問、第3部は番号付き英文3択を台本にします。質問の二重収録・話者記号の読み上げを避けています。

### まずは課金なしで確認

Node.js 22以降。マニフェストを既に同梱しているので、dry-runだけならサーバー・APIキー・Genspark CLIは不要です。

```sh
npm run media:images
npm run media:audio
# デフォルトはdry-run、1件のみ。全計画の確認:
npm run media:images -- --limit 100
npm run media:audio -- --limit 100
```

問題内容を更新した場合、プレビューサーバーを起動して再エクスポートします。この処理も生成APIを呼びません。

```sh
npm run media:manifest
# 必要に応じて接続先・セットを指定
npm run media:manifest -- --base http://localhost:3000 --sets 2026-2,2026-1,2025-3
```

### 後から有料生成する場合

**`--execute` と `--confirm-cost` を両方指定したときだけ外部生成APIを呼びます。以下は実行例であり、今回の作業では未実行です。**

- 画像: `gsk` CLIのインストールとローカル認証、利用可能なプラン・クレジットが必要です。モデルは `nano-banana-2-flash-lite`、4:3、1K。PNG出力を検証します。
- 音声: 自分のElevenLabsアカウントの `ELEVENLABS_API_KEY` と `ELEVENLABS_VOICE_ID` をローカル環境変数に設定します。スクリプトは `.env` を自動読込しません。キーをソースやコマンド履歴に残さないでください。モデルは `eleven_multilingual_v2`。同一のプリセット話者を全問に使用します。

```sh
# 費用を確認してから1件ずつ実行
npm run media:images -- --execute --confirm-cost --limit 1
npm run media:audio -- --execute --confirm-cost --limit 1
# 任意の素材IDだけ実行
npm run media:images -- --only image-REPLACE_WITH_MANIFEST_HASH --execute --confirm-cost
```

- `--manifest PATH` / `--output-dir DIR` / `--only ID` / `--limit N` を指定できます。
- 出力先は既定で `.media-output/`。git管理対象外で、公開ディレクトリの外です。
- 既存ファイルはスキップ。`--force` は再生成・再課金を伴い得ます。失敗時の自動リトライは行いません。タイムアウト後は提供元履歴を確認して二重課金を避けてください。
- 生成後は図版と正答の一致、時計・数・位置関係、グレースケールでの識別性、発音・数字・間合い、権利を人が確認してください。色が答えになる場面は白黒図版向けに設問の再設計が必要です。
- 音声は1問1ファイル・1話者。2回放送、解答待ち時間、対話の複数話者化は未対応です。
- **生成物のWeb画面への自動反映・自動公開は行いません。現在の絵文字・説明文とブラウザ音声を維持します。採用する場合はレビュー後に教材と配信処理を更新してください。**
