# 英検5級 過去問演習アプリ（ローカル版）

英検5級の一次試験（リーディング25問・リスニング25問）を、本番と同じ形式で解ける Web アプリです。
アップロードされた公式PDF（過去問・解答・リスニング原稿）をもとに、試験内容と出題形式を再現しています。

**ローカル専用**です（GitHub への push・Cloudflare へのデプロイは行っていません）。

---

## 画面・URL

実際の英検サイト（`5級の過去問・試験内容` ページ）と同じレイアウトで構成しています。

| パス | 内容 |
| --- | --- |
| `/` | 5級の過去問・試験内容（公式サイト風のトップ） |
| `/exam/2026-2` | 2026年度第2回 通し演習（リーディング25問＋リスニング25問） |
| `/exam/2026-2?part=reading` | リーディングのみ（25分） |
| `/exam/2026-2?part=listening` | リスニングのみ（約22分） |
| `/exam/2026-1` / `/exam/2025-3` | 2026年度第1回 / 2025年度第3回 |
| `/exam/{id}?show=answers` | 解答・解説つきで表示 |
| `/answers/2026-2` | 解答一覧（マークシート風の正解表） |
| `/script/2026-2` | リスニング原稿（英文＋和訳） |
| `/new` | **オリジナル問題を自動生成**（毎回ちがう25問） |
| `/new?part=reading` / `?part=listening` | 生成問題のリーディングのみ / リスニングのみ |
| `/api/sets` | 収録セット一覧（JSON） |

問題セットID: `2026-2`（2026年度第2回・10/4実施）、`2026-1`（第1回・5/31実施）、`2025-3`（2025年度第3回・1/25実施）。

## 実装済みの機能

- **本番同様の出題構成**：大問1（短文の語句・文法15問）／大問2（会話文補充5問）／大問3（語句並べかえ5問）、リスニング第1部（10問）／第2部（5問）／第3部（10問）
- **2026年度第2回は公式解答どおり**：`202602F5kyu.pdf` の解答（リーディング 1〜25、リスニング第1〜3部）と問題を一致させています
- **リスニング音声**：ブラウザの音声合成（Web Speech API / en-US）で読み上げ。「ゆっくり再生」も可能。英文は2回までの再生制限は設けず、何度でも再生できます
- **タイマー**：リーディング25分／リスニング22分／通し47分。停止・再開可。残り1分で赤表示
- **解答進捗バー**：解答済み問題数をその場で表示
- **自動採点**：正答数・正答率・分野別スコア（大問1〜3／リスニング第1〜3部）・全問の○×一覧
- **解説表示**：採点後に各問へ正解・和訳・文法解説を差し込み。`?show=answers` では最初から解説つき
- **語句並べかえ**：4つの語句（①②③④）から「1番目と3番目の組合せ」を選ぶ実際の形式を再現（誤答選択肢は自動生成）
- **オリジナル問題の自動生成**：動詞の形（3単現・原形・進行形・過去形）、所有代名詞、be動詞の一致、場所の前置詞、疑問詞の5種類のテンプレートで文法が必ず正しい問題を生成。過去問プールと組み合わせて毎回ちがうセットを作成
- **公式サイト風UI**：赤（#e50111）基調、2段ヘッダー、グローバルナビ、下部固定の級タブ（1級〜5級）、パンくず、赤いピル型ボタン

## 未実装・今後の候補

- スピーキングテスト（録音・判定）は未実装。ページ内では紹介のみ
- 結果の保存（履歴・間違えた問題の復習リスト）。現在はリロードでリセット
- 音声は音声合成のため、公式音源（ネイティブ音声）とは発音・間合いが異なります
- 1〜4級、準2級プラスは準備中（タブは表示のみ）
- 画像イラスト（リスニング第3部）は絵文字＋説明文で代替

## データ構成

```
src/data/reading.ts    大問1(45) / 大問2(20) / 大問3(22) の素材
src/data/listening.ts  リスニング第1部(20) / 第2部(11) / 第3部(18) の素材
src/data/generate.ts   テンプレート型の自動生成（文法保証つき）
src/data/sets.ts       セット組み立て・選択肢シャッフル・生成セットの復元
src/views/home.tsx     公式サイト風トップ
src/views/exam.tsx     演習画面・解答一覧・リスニング原稿
src/renderer.tsx       共通レイアウト（ヘッダー／級タブ／フッター）
public/static/app.js   採点・タイマー・音声読み上げ・進捗
public/static/style.css スタイル一式
```

データはすべてコード内に静的に保持（DB・外部APIなし）。採点もブラウザ内で完結します。

## 起動方法

```bash
cd /home/user/webapp
npm run build
pm2 start ecosystem.config.cjs   # http://localhost:3000
```

開発時は `npx wrangler pages dev dist --ip 0.0.0.0 --port 3000`（PM2設定と同一）。

## 技術スタック

- Hono + TypeScript（Cloudflare Pages / Workers ランタイム）
- Vite ビルド、JSX は hono/jsx
- フロントは素の JavaScript（ビルド不要）、CDN 依存なし
- 音声：Web Speech API（`speechSynthesis`）

## 出典・注意

問題文はアップロードされた公式過去問PDF（公益財団法人 日本英語教育協会）の出題形式・語彙レベルに基づいて構成しています。公式教材の転載ではなく、学習用に再構成した演習アプリです。
