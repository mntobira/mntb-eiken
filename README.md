## 完了した修正

### ホーム・ガチャ

- 保存データが読み込めない場合も、表示専用の初期値でとびらくんを表示。破損した保存データを上書きしません。
- 装備画像の読込失敗時は既存の基本画像へフォールバック。静止時はWebKitの裏面描画に依存しないCSSに変更。
- ガチャの目玉が存在しない教材URを前提として空になる経路を修正。実際のプールから目玉1件・重複しないピックアップ5件を選びます。
- 旧プールIDは保存互換性のため保全し、表示と内容を英検用に改訂。
- 英検5級〜準1級の重点語ノートPDF **7冊・各5ページ、計35ページ**を作成。30語の意味・独自例文・和訳、確認テスト、解答を収録。PDFのページ数・文字の存在・サムネイル・プレビューを生成時に検証。
- 基礎側プールは5級〜準2級の4冊、上位側は準2級プラス〜準1級の3冊。教材と同じ内容は無料のアプリ内単語帳でも使えます。
- 提供割合は空のレア度を除いて正規化した実際の抽選表を表示。注目表示で排出率が上がるとは表示しません。
- 共通の抽選・重複返還・11連・成長・装備の仕組みとブランド素材は維持。

### 級別の学習

- 公開7級：5級、4級、3級、準2級、準2級プラス、2級、準1級。1級は準備中。
- 素材内に残存していたリーディング **14本文・28設問**を復元。
- 語彙文法 **14設問**と、従来の聞き取り **14設問**を共通の採点・解説・復習へ接続。合計56設問、42大問、21単元。

## 利用方法・配信パス

1. ホームの「演習する」→級→分野→問題→解説・結果。
2. 学習カタログの単語帳で級を選び、例文と意味を確認。「4択・間違えた語の復習」へ進む。
3. 学習や対戦で得た報酬は成長・ガチャ・着せ替えの共通画面で利用。獲得PDFはマイページの「マイPDF」へ。
4. BGMはホームの音ボタン、音量は設定で変更。

- SPA入口：`/`。画面・級はURLルーターではなくアプリ状態で保存。
- `/?screenshot=1`：既存の画面検証起動。通常の初回起動確認とは別。
- `/data/listeningVocabulary.json?v=eiken-wordbook-20261110`：英検級別単語JSON。
- `/prints/print_eiken_wordbook_<grade>.pdf`：獲得したノート。gradeは`5,4,3,pre2,pre2plus,2,pre1`。
- `/tanjou.mp3`、`/bgm/battle/`、`/sfx/`、`/cinematics/`、`/fonts/`、`/brand/`、`/mascots/`：既存静的素材。
- `/manifest.json`、`/sw.js`：英検専用PWA。

## 保存・Firebase・Vercel

- 端末保存：`eiken:v1:`。選択級、問題記録、復習、成長、音設定を大学受験版と分離。
- クラウド有効時は英検専用Firebase App `manatobi-eiken`を使用し、ルートコレクションは`eiken_`。
- 設定は`VITE_EIKEN_ENABLE_CLOUD`と`VITE_EIKEN_FIREBASE_*`。元版の`VITE_FIREBASE_*`や大学受験プロジェクトIDはビルドガードで拒否。
- ローカルはクラウド無効で検証。本番ルールは`eiken-app/firestore.rules`、索引は`eiken-app/firestore.indexes.json`。ルート`firebase.json`が参照。
- 本番Auth、許可ドメイン、フレンド／クラス、2端末通信、Functionsは実環境で別途確認が必要。

既存Vercel設定：Root Directoryはリポジトリ直下、Installは`npm ci --prefix eiken-app`、Buildは`npm --prefix eiken-app run build:vercel`、Outputは`eiken-app/dist`、Production Branchは`main`、Node22.18以上。Rootを`eiken-app`とする代替設定と混在させないでください。標準Hono／Cloudflare用のルートビルドへ置き換えません。
